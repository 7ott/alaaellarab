# ربط كومنتات صفحة العراب بالسيستم

بعد الخطوات دي، أي كومنت على بوستات صفحة العراب فيه طلب عقار (مطلوب / عندي للبيع) هيدخل السيستم لوحده كل 15 دقيقة، وتقدر كمان تسحب فورًا من زرار **"اسحب كومنتات الصفحة"** في السيستم.

> ⚠️ توكن الصفحة زي كلمة السر. ما تبعتهوش لحد ولا تكتبه في الشات — حطه في Supabase بس.

---

## الجزء الأول: هات رقم الصفحة والتوكن من فيسبوك

### ١. اعمل تطبيق فيسبوك (مرة واحدة)
1. ادخل **developers.facebook.com** بحسابك اللي أدمن على صفحة العراب.
2. **My Apps** ← **Create App**.
3. اختار **Other** ← Next ← نوع **Business** ← Next.
4. اسم التطبيق: `Al-Arrab Radar` ← **Create app**.
   (التطبيق يفضل في وضع Development، ده كفاية لصفحتك إنت.)

### ٢. هات توكن مؤقت
1. افتح **Graph API Explorer**: developers.facebook.com/tools/explorer
2. فوق على اليمين في **Meta App** اختار `Al-Arrab Radar`.
3. في **Permissions** ضيف التلاتة دول:
   - `pages_show_list`
   - `pages_read_engagement`
   - `pages_read_user_content`
4. اضغط **Generate Access Token**، ووافق، واختار صفحة **العراب** لما يسألك.

### ٣. خليه توكن دايم
1. انسخ التوكن اللي ظهر في الخانة.
2. افتح **Access Token Debugger**: developers.facebook.com/tools/debug/accesstoken
3. الصق التوكن ← **Debug** ← انزل تحت واضغط **Extend Access Token** ← انسخ التوكن الجديد الطويل.
4. ارجع للـ Graph API Explorer، امسح التوكن اللي في الخانة والصق الطويل مكانه.
5. في خانة الطلب اكتب:
   ```
   me/accounts?fields=id,name,access_token
   ```
   واضغط **Submit**.
6. هيظهرلك صفحاتك. عند صفحة **العراب** انسخ:
   - `id` ← ده **FB_PAGE_ID**
   - `access_token` ← ده **FB_PAGE_TOKEN** (التوكن ده مش بيخلص)

---

## الجزء التاني: Supabase

### ٤. ارفع الدالة
1. في Supabase: **Edge Functions** ← **Deploy a new function** ← **Via Editor**.
2. اسم الدالة بالظبط: `fb-comments`
3. امسح الكود اللي فيه، والصق محتوى ملف `fb-comments/index.ts` كله ← **Deploy function**.
4. افتح الدالة ← **Details** (أو Settings) ← اقفل **Enforce JWT verification** (Verify JWT) ← Save.
   (الحماية معمولة جوه الدالة نفسها: محدش يشغلها غير الجدولة أو إنت وإنت داخل السيستم.)

### ٥. حط الأسرار
**Edge Functions** ← **Secrets** (أو Project Settings ← Edge Functions) ← **Add new secret**، ضيف الأربعة:

| الاسم | القيمة |
|---|---|
| `FB_PAGE_ID` | رقم الصفحة من الخطوة ٣ |
| `FB_PAGE_TOKEN` | توكن الصفحة من الخطوة ٣ |
| `CRON_SECRET` | الكلمة اللي في ملف `update-facebook.sql` (في السطر اللي فيه x-cron-secret) |
| `OWNER_EMAIL` | إيميلك اللي بتدخل بيه السيستم |

### ٦. شغّل الجدولة
**SQL Editor** ← الصق `update-facebook.sql` ← **Run**.

### ٧. ارفع السيستم الجديد
ارفع `app.html` الجديد مكان القديم على Vercel.

## جرّب
1. من حسابك الشخصي اكتب كومنت على أي بوست في صفحة العراب، مثلًا:
   `مطلوب شقة في بني سويف الجديدة في حدود مليون ونص`
2. في السيستم اضغط **"اسحب كومنتات الصفحة"**.
3. المفروض يظهر "اتضاف 1 طلب جديد" والطلب يظهر في السجل كـ **مشتري**.

## لو ظهر خطأ
- **"FB_PAGE_ID / FB_PAGE_TOKEN مش متحطين"** ← راجع الخطوة ٥ (الأسماء لازم تبقى بالظبط).
- **"Facebook: ... token ..."** ← التوكن غلط أو منتهي؛ أعد الخطوة ٣ وتأكد إنك نسخت `access_token` بتاع الصفحة مش بتاعك.
- **"not allowed"** ← `OWNER_EMAIL` مش نفس إيميل دخولك، أو `CRON_SECRET` مش نفس اللي في SQL.

## إيه اللي بيتسحب؟
- الكومنتات الرئيسية على آخر 25 بوست في صفحتك.
- بس الكومنتات اللي فيها نوع عقار + (مطلوب/عايز/محتاج أو للبيع/عندي). الكومنتات زي "شكرًا" و"تم" والمنشن بتتساب.
- ردودك إنت كصفحة مش بتتسحب.
- نفس الكومنت مش بيتضاف مرتين.
